OVERLAY STUDIO — EARLY WINDOWS BUILD (0.5.0)

1. Extract the ENTIRE ZIP into a folder on your Windows x64 computer.
2. Open Overlay Studio.exe. Keep all of the adjacent files and folders.
3. Start with PLAYER text, type your own wordmark, or Import PNG / JPEG logo.
   The original Cudi example is optional under Reference presets.
   New neutral design resets the editor; Undo restores your previous work.
4. Choose Gamepad base color, accent colors, glow and breathing speed.
   Move controller is selected by default: grab the preview and drag.
   Choose Move artwork to drag custom text or a logo separately.
   Center controller restores its position. Arrow keys nudge the selected
   target; hold Shift for 10 pixels. Content outside the canvas is cropped.
5. Use Peak glow and the input preview buttons to check legibility.
6. Save project to keep an editable .overlay file with its artwork embedded.

OBS
Choose Export & OBS, then Create / update OBS URL. Add a Browser Source with this URL:
http://127.0.0.1:18777/overlay
Set Width 1672 and Height 1241. Keep Overlay Studio running.
After updating the design, create/update the URL again, then refresh the source
in OBS. Turn off "Shutdown source when not visible" if you want the connection
to stay open between scenes.

LIVE CONTROLLER INPUT
Connect the controller, focus the editor, and press a button. The connection
label shows detection. Live controller lets you inspect standard buttons,
sticks and trigger pressure. The OBS bridge always sends physical controller
input; preview simulations are never sent to OBS.
Only devices reported with standard browser gamepad mapping are supported.
GameSir M and vendor-specific controls have no live mapping in this build.
Home/Capture availability depends on what Windows/browser exposes.
Keep the editor open and visible for the initial physical-controller check.
The local bridge uses port 18777; run one copy of Overlay Studio at a time.

EXPORTS
Export overlay HTML creates a self-contained visual with embedded artwork.
Its live input still comes from the running desktop app on this computer.
Export PNG still creates a transparent image at peak glow; it has no motion.
Save project creates an editable JSON-based .overlay project.
Autosave is a convenience; use Save project for backups, especially large logos.

OFFLINE
After downloading and extracting this build, no installation, account, internet,
Node.js or separate GameSir server is needed to run it. The OBS bridge is local.

EARLY BUILD LIMITS
The original Cudi appearance is reused from your supplied CSS. This is a
raster/vector template, not an editable 3D controller model. Base color is a tint of the existing shell and controls, retaining their
texture and seams; the original neutral base contains faint baked artwork.
New logos do not recreate a physical printed finish automatically. Rotation and
position controls affect custom text/logos; Original Cudi placement stays fixed.
The native GameSir frontend is not included and this app does not patch it.

Verified here: Chromium editing, save/open, undo/redo, autosave, invalid project
handling, responsive layouts and independently rendered exported HTML. Local
publish/SSE bridge and native save handlers were tested with a mocked Electron
shell. The packaged Windows application, physical G7 8K and actual OBS capture
still require testing on Windows. This is an unsigned early build.

INDIVIDUAL COLORS AND EFFECTS
In Individual button colors, choose a button. Uncheck Use default button color
or Use global pressed color to set a custom color. Resting and pressed colors
are independent. Preview selected press shows that input; Clear input preview
releases all simulated inputs. Reset all button colors restores inheritance.
All 19 controls have color settings, including each D-pad direction, L3/R3,
LT/RT and Home. Vendor-only inputs can still only be previewed until a host
adapter provides them.

Special effects has None, Rainbow accents, Neon pulse and Reactive input flash.
Intensity changes the strength. Cycle controls rainbow/neon animation timing.
Reactive flash is clipped to the shell and fades over 600 ms after release.
Effects are applied by the same renderer in preview, OBS, HTML and PNG exports.
PNG exports remain still images. Re-send to OBS and refresh the source after
changing your design. Old projects inherit the global colors with effects off.

NEW MENU AND FONT LIBRARY
Shell: main base/accent/input colors.
Buttons: individual colors; click a button on the preview to select it.
Artwork: text/logo, font library or installed fonts, weight, italic, size/angle.
Effects: rainbow/neon/reactive, with ambient settings under the disclosure.
Layout: grab-to-move controls, centering, and optional precise coordinates.
Project options holds the New neutral design button.
Export & OBS opens the OBS setup, HTML export and PNG export dialog.

Included offline fonts: Rajdhani, Orbitron, Oxanium, Teko, Bebas Neue,
Barlow Condensed, Montserrat and Inter. Their SIL Open Font Licenses are
included under resources/app.asar (app/fonts/licenses in the source).
The selected included font is embedded with its license in exported HTML.
Windows installed-font discovery reads family names using System.Drawing.
System fonts are used locally and are not copied into the export: install the
same font on other computers before displaying that overlay there.

SHELL SEPARATION AND ANIME PRESETS (0.5)
Shell color no longer recolors buttons, sticks, bumpers or triggers. Use
Buttons > All-button defaults for a separate resting/pressed palette. Individual
button overrides remain independent. Older projects keep their previous default
button color when opened; future shell edits leave it alone.

Presets contains 16 anime-inspired palettes with original procedural patterns,
fonts and effects. Applying a preset preserves positions, angles and artwork size.
Uncheck Include preset wordmark to preserve your own text/logo and font choices.
Undo restores the entire previous design in one step. All settings remain editable.

Seven additional effects: Energy aura, Aura waves, Lightning, Manga speed lines,
Drifting embers, Halftone pulse and Energy sweep. Shell patterns/effects avoid
physical controls. Included preset artwork is procedural motifs and wordmarks,
rather than character illustrations. All presets and effects work offline.
